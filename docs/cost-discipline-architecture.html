Architectural invariants

  • Five entry points, not six. There is no Stop or SubagentStop handler — the hook never sees a session end.
  • The header describes a smaller program. It omits UserPromptSubmit, which carries all four pulses.
  • Only pre-tool can refuse a call. Every other handler is advisory; they emit context and cannot stop anything.
  • The two read counters reset differently. Any non-read clears read_streak; only a dispatch or /clear clears aggregate_reads.
  • Skills are named, never invoked. All nine references are advisory text in a message — the hook calls no skill programmatically.

cost-discipline.py — architecture

Five harness events enter one file. It keeps six pieces of state across three scopes, runs five counters that reset by different rules, and fires four pulses on a prompt — only one of which is throttled the way the others are.
